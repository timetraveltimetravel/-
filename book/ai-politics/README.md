# AI정치 — 지금 체제 그대로, 주체만 바꾼다

원고 1판(2026-10-22 마무리). 저자의 진술 N1~N55(analysis/author.md)를 반영했다.

## 파일

| 파일 | 내용 |
|---|---|
| `polished.md` | **다듬은 판(원고 2판).** 장별 초고를 합쳐 다듬은 한 권짜리 원고. 표를 모두 글로 풀고, 장 사이의 중복과 괄호 참조를 줄였다. 작업 노트는 넣지 않았다. |
| `AI정치_다듬은원고.hwpx` | 다듬은 판의 한글 파일. `build_polished.py`로 만든다. |
| `manuscript.md` | 합친 원고. 서론부터 맺음까지 차례대로 잇고, 장마다의 근거와 확인을 책 끝 부록으로 모았다. |
| `ch00-introduction.md` ~ `ch07-conclusion.md` | 장별 원고. 원본은 이 파일들이다. 각 파일 끝에 '근거와 확인'이 있다. |
| `outline.md` | 목차. 원고에 맞춰 고쳤다. |
| `questions.md` | 원고 확인 질문과 저자의 답(N52~N55). |
| `merge_book.py` | 장별 원고를 `manuscript.md`로 합치는 스크립트. |
| `factcheck.md` | 법 조문, 결정, 숫자를 원문과 대조한 기록. |
| `AI정치_종합정리.hwpx` | 한글 파일 종합 정리본. 1부 한눈에 보기, 2부 원고 전문, 3부 부록(작가가 정한 것, 사실 확인, 나중에 고칠 것, 표기, 근거와 확인). |
| `종합정리.md` | 위 한글 파일의 원본 마크다운. `build_hwpx.py`가 만든다. |
| `overview.md`, `decisions-summary.md` | 종합 정리본의 1부(한눈에 보기)와 부록 가(작가가 정한 것). |
| `build_hwpx.py` | 종합 정리본을 엮어 한글 파일로 만드는 스크립트. |
| `build_polished.py`, `hwpx_writer.py` | 다듬은 판을 한글 파일로 만드는 스크립트와, 두 빌드 스크립트가 함께 쓰는 변환 모듈. |

장은 이렇다.
- 서론 — 지금 체제 그대로, 주체만 바꾼다
- 1장 왜 사람이 집행하면 문제가 생기는가
- 2장 AI정치란 무엇인가
- 3장 AI가 사람보다 나은 점
- 4장 어떻게 뽑고 어떻게 지키는가
- 5장 반박과 답
- 6장 한계
- 맺음 — 이보다 더 좋은 체제를 아직 모른다

## 고치는 법

장별 파일을 고친 뒤, 이 폴더에서 아래를 실행해 합친 원고를 다시 만든다.

```
python3 merge_book.py .
```

한글 종합 정리본을 다시 만들려면 python-hwpx가 필요하다.

```
pip install python-hwpx==6.8.0
python3 build_hwpx.py .      # 종합 정리본
python3 build_polished.py .  # 다듬은 판
```

다듬은 판(polished.md)은 장별 초고에서 자동으로 만들지 않는다. 초고를 고치면 다듬은 판도 손으로 맞춰 고친다.

## 표기

- 「」: 저자가 한 말 그대로. 원문은 analysis/author.md(N 번호)와 analysis/source.md(U 번호)에 있다.
- **〔제안〕**: 저자가 말한 적 없이 분석이 더한 것. 저자가 뒤에 받아들인 것에는 "저자가 받아들였다(N54)"처럼 적었다.
- N: 저자 진술(analysis/author.md). B: 대화 속 주장(analysis/claims.md). F: 분석의 발견(analysis/findings.md). G: Gemini의 발언(analysis/source.md).

## 사실 확인

2026-10-22에 법 조문, 헌법재판소 결정, 예산, 법령 수, 최근 판결을 원문과 공식 통계로 대조했다. 기록은 `factcheck.md`에 있다. 틀린 곳은 없었다. 법령 수는 '수천 개'를 '5,600개가 넘는다'로 구체적으로 고쳤다.
