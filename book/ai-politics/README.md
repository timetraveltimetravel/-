# AI정치 — 지금 체제 그대로, 주체만 바꾼다

원고 1판(2026-10-22 마무리). 저자의 진술 N1~N55(analysis/author.md)를 반영했다.

## 파일

| 파일 | 내용 |
|---|---|
| `manuscript.md` | 합친 원고. 서론부터 맺음까지 차례대로 잇고, 장마다의 근거와 확인을 책 끝 부록으로 모았다. |
| `ch00-introduction.md` ~ `ch07-conclusion.md` | 장별 원고. 원본은 이 파일들이다. 각 파일 끝에 '근거와 확인'이 있다. |
| `outline.md` | 목차. 원고에 맞춰 고쳤다. |
| `questions.md` | 원고 확인 질문과 저자의 답(N52~N55). |
| `merge_book.py` | 장별 원고를 `manuscript.md`로 합치는 스크립트. |

장은 이렇다.
- 서론 — 지금 체제 그대로, 주체만 바꾼다
- 1장 왜 사람이 집행하면 문제가 생기는가
- 2장 AI정치란 무엇인가
- 3장 AI가 사람보다 나은 점
- 4장 어떻게 뽑고 어떻게 지키는가
- 5장 반박과 답
- 6장 한계
- 맺음 — 이보다 더 좋은 체제를 아직 모른다

## 고치는 법

장별 파일을 고친 뒤, 이 폴더에서 아래를 실행해 합친 원고를 다시 만든다.

```
python3 merge_book.py .
```

## 표기

- 「」: 저자가 한 말 그대로. 원문은 analysis/author.md(N 번호)와 analysis/source.md(U 번호)에 있다.
- **〔제안〕**: 저자가 말한 적 없이 분석이 더한 것. 저자가 뒤에 받아들인 것에는 "저자가 받아들였다(N54)"처럼 적었다.
- N: 저자 진술(analysis/author.md). B: 대화 속 주장(analysis/claims.md). F: 분석의 발견(analysis/findings.md). G: Gemini의 발언(analysis/source.md).

## 인쇄 전에 확인할 것

- **법 조문.** 헌법·공직선거법·국가배상법·정당법 조문과 헌법재판소 결정(95헌바3, 2004헌나1)은 검색 결과로 확인했다. 조문 페이지는 직접 열어 대조하지 못했다. 국가법령정보센터(law.go.kr)에서 한 번 더 대조한다.
- **최근 보도에 기댄 것.** 1장 근거 노트의 윤석열 전 대통령 판결(2026년 보도)은 다시 확인한다.
- **바뀌는 숫자.** 1장의 예산(2026년도 본예산 727.9조 원)은 새 해 예산이 확정되면 고친다.
- **확인하지 못한 것.** 1장의 "법령은 수천 개"는 출처를 찾지 못했다.
