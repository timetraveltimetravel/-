# 스크롤 캡처

웹 페이지를 스크롤할 때 화면을 캡처하고, 사진으로 저장하는 Chrome 확장 프로그램입니다.
프로그램은 겹친 부분을 자르고, 사진을 이어 붙여서 긴 사진 한 장을 만듭니다.
프로그램은 사진 안의 글자를 텍스트로 변환할 수도 있습니다.

- 버전: 0.4.0
- 대상 브라우저: Chrome 116 이상, Edge (데스크톱)
- 서버를 사용하지 않습니다. 프로그램은 사진을 외부로 보내지 않습니다.

## 설치

1. 이 `scroll-capture` 폴더를 컴퓨터에 저장합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위의 "개발자 모드"를 켭니다.
4. "압축해제된 확장 프로그램을 로드합니다"를 누릅니다.
5. `scroll-capture` 폴더를 선택합니다.
6. 도구 모음의 퍼즐 아이콘을 누르고, "스크롤 캡처"를 고정합니다.

## 자동 업데이트

자동 업데이트는 git으로 설치한 폴더에서 동작합니다 (Windows). 압축 파일로 설치한 폴더에서는 동작하지 않습니다.

자동 업데이트에는 두 부분이 있습니다.

| 부분 | 하는 일 |
| --- | --- |
| Windows의 예약 작업 `ScrollCapture-AutoUpdate` | 60분마다 `auto-update/pull.ps1`을 실행합니다. `pull.ps1`은 `git pull --ff-only`로 새 파일을 받습니다 |
| 확장 프로그램 | 5분마다 폴더의 `manifest.json`의 버전을 읽습니다. 버전이 실행 중인 버전과 다르면 스스로 다시 로드합니다 |

예약 작업을 등록하는 명령 (한 번만 실행합니다. 관리자 권한은 필요하지 않습니다):

```bash
powershell -ExecutionPolicy Bypass -File auto-update\install.ps1
```

예약 작업을 제거하는 명령:

```bash
powershell -ExecutionPolicy Bypass -File auto-update\uninstall.ps1
```

- 측면 패널이 열려 있으면 프로그램은 다시 로드하지 않습니다. 캡처한 사진이 없어지기 때문입니다.
  이때 측면 패널이 "새 버전이 있습니다" 알림을 보여줍니다. 측면 패널을 닫으면 프로그램이 5분 안에 새 버전을 적용합니다.
  "지금 적용"을 누르면 바로 적용합니다.
- 새 버전을 적용한 후에는 아이콘을 다시 누르십시오. 측면 패널의 아래쪽에 버전이 있습니다.
- 프로그램은 버전이 바뀐 때에만 다시 로드합니다.
- `pull.ps1`은 결과를 `auto-update/update.log`에 기록합니다 (마지막 200줄).
- 폴더의 파일을 직접 바꾸면 `git pull`이 실패할 수 있습니다. 실패의 이유는 `update.log`에 있습니다.
- 폴더를 다른 위치로 옮기면 `install.ps1`을 다시 실행하고, Chrome에서 확장 프로그램을 다시 로드하십시오.
- 확장 프로그램은 외부로 요청을 보내지 않습니다. 외부와 통신하는 것은 git뿐입니다.
- 자동 업데이트는 저장소의 브랜치에 있는 파일을 확인 없이 설치합니다. 그 브랜치에 쓸 수 있는 사람만 신뢰하십시오.

## 사용 방법

1. 캡처할 웹 페이지를 엽니다.
2. "스크롤 캡처" 아이콘을 누릅니다. 측면 패널이 열립니다.
3. "캡처 시작"을 누릅니다.
4. 페이지를 스크롤합니다. 또는 "자동 스크롤"을 누릅니다.
5. "정지"를 누릅니다. 그 다음에 "사진 저장"을 누릅니다.

프로그램은 사진을 "다운로드" 폴더에 저장합니다. 파일 이름은 `페이지 제목_날짜_번호`입니다.

### 텍스트 변환

1. 캡처를 끝낸 후에 "텍스트 변환"을 누릅니다.
2. 변환이 끝나면 측면 패널이 텍스트를 보여줍니다. 내용을 확인하고, 필요하면 수정합니다.
3. "TXT 저장" 또는 "복사"를 누릅니다.

TXT 파일의 첫 부분에는 페이지의 제목, 주소, 날짜가 있습니다.
변환은 브라우저 안에서 수행합니다. 프로그램은 사진과 텍스트를 외부로 보내지 않습니다.

### 수동 스크롤

수동 스크롤에서는 스크롤을 멈출 때마다 프로그램이 화면을 한 번 캡처합니다.
한 번에 한 화면보다 많이 스크롤하지 마십시오. 캡처하지 않은 영역이 있으면 "누락 영역"의 수가 증가합니다.

## 설정

| 항목 | 설명 |
| --- | --- |
| 자동 스크롤 속도 | 느림, 보통, 빠름, 자연스럽게. 페이지가 내용을 늦게 불러오면 "느림"을 선택하십시오 |
| 자연스럽게 (사람처럼) | 프로그램이 사람의 손 동작과 같이 스크롤합니다. 아래의 "자연스러운 스크롤"을 보십시오 |
| 자동 스크롤의 최대 화면 수 | 프로그램은 이 수의 화면을 캡처한 후에 정지합니다. 끝이 없는 페이지에 필요합니다 |
| 고정 메뉴 숨기기 | 첫 사진 다음부터, 화면에 고정된 메뉴와 알림 띠를 숨깁니다. 정지하면 다시 보입니다 |
| 형식 | PNG (화질 손실 없음) 또는 JPEG (작은 파일) |
| 저장 방식 | 긴 사진 한 장, 또는 화면별 여러 장 |

## 자연스러운 스크롤

"자연스럽게 (사람처럼)" 속도는 다음 동작을 조합합니다. 동작의 종류, 거리, 시간은 매번 다릅니다.

| 동작 | 설명 |
| --- | --- |
| 끌기 | 화면을 누른 채로 천천히 이동합니다 (1초에 약 140~420 픽셀). 속도가 조금 변하고, 가끔 잠시 멈춥니다 |
| 계속 끌기 | 손을 떼지 않고 다음 끌기를 시작합니다. 멈춤 시간이 매우 짧습니다 |
| 튕기기 | 빠르게 시작하고, 천천히 멈춥니다 |
| 휠 돌리기 | 짧은 이동을 여러 번 합니다. 이동 사이에 짧게 멈춥니다 |
| 위로 돌아가기 | 가끔 위로 이동하고, 그 다음에 다시 아래로 이동합니다 |
| 읽기 | 이동한 후에 멈춥니다. 가끔 길게 멈춥니다 (1.5~3.5초 추가) |

프로그램은 화면이 멈춘 순간에만 캡처합니다. 프로그램은 캡처하지 않은 영역이 생기는 거리를 이동하지 않습니다.
이 속도는 일정한 속도보다 시간이 많이 걸립니다 (시험 페이지에서 약 2~3배).

## 제한 사항

- Chrome은 화면 캡처를 1초에 2회로 제한합니다. 그래서 프로그램은 스크롤이 멈춘 화면만 캡처합니다.
- 사진의 길이가 30,000 픽셀을 넘으면 프로그램이 긴 사진을 여러 장으로 나눕니다.
- 프로그램은 `chrome://` 페이지와 Chrome 웹 스토어 페이지를 캡처할 수 없습니다.
- 캡처 권한은 아이콘을 누른 탭에만 있습니다. 다른 사이트로 이동한 후에는 아이콘을 다시 누르십시오.
- 캡처 중에는 캡처 대상 탭이 화면에 보여야 합니다.
- 캡처는 화면에 보이는 모든 것을 저장합니다. 저장 전에 미리 보기에서 개인 정보를 확인하십시오.
- "자연스럽게" 속도는 스크롤의 움직임만 바꿉니다. 프로그램은 사이트의 접근 제한을 우회하지 않습니다. 각 사이트의 약관을 확인하십시오.

### 텍스트 변환의 제한 사항

- 텍스트 변환은 한국어와 영어를 인식합니다. 다른 언어는 인식하지 않습니다.
- 인식 오류가 있습니다. 시험 페이지에서 글자 오류율은 0.5~3%입니다. 한글과 영문이 붙어 있는 부분, 작은 글자, 사진 위의 글자에서 오류가 많습니다. 저장 전에 내용을 확인하십시오.
- 변환 시간은 페이지 1,000 픽셀에 약 3초입니다 (시험 환경의 값).
- 텍스트의 줄 바꿈은 화면의 줄 바꿈과 같습니다. 문단의 구분은 유지하지 않습니다.
- 표와 여러 단으로 구성된 페이지는 글자의 순서가 바뀔 수 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 확장 프로그램의 설정과 권한 |
| `background.js` | 아이콘을 누르면 측면 패널을 엽니다. 폴더의 버전을 확인하고, 새 버전이 있으면 다시 로드합니다 |
| `update.js` | 자동 업데이트의 판단: 다시 로드, 알림, 대기 |
| `auto-update/` | 예약 작업의 스크립트: `pull.ps1`, `install.ps1`, `uninstall.ps1` |
| `content.js` | 페이지 스크립트. 스크롤 위치를 읽고, 자동 스크롤을 수행합니다 |
| `sidepanel.html`, `sidepanel.css`, `sidepanel.js` | 측면 패널. 캡처를 제어하고, 사진을 보관하고, 파일로 저장합니다 |
| `stitch.js` | 겹친 부분을 계산하고, 사진을 이어 붙이는 계획을 만듭니다 |
| `pace.js` | 자동 스크롤의 이동 거리와 시간을 계산합니다 |
| `ocr.js`, `ocr-tiles.js` | 사진을 조각으로 나누고, 글자를 텍스트로 변환합니다 |
| `vendor/tesseract/` | 글자 인식 엔진 Tesseract.js 7.0.0과 언어 자료 (한국어, 영어). 약 8MB |
| `tests/` | 자동 시험 |

## 시험

시험에는 Node.js 22 이상과 Playwright의 Chromium이 필요합니다.

단위 시험 (이어 붙이기, 스크롤 속도, 조각 나누기의 계산):

```bash
node --test tests/*.test.mjs
```

브라우저 시험 (실제 Chromium에서 캡처하고, 결과 사진의 모든 픽셀 줄을 확인합니다):

```bash
node tests/e2e.mjs
```

브라우저 시험은 Playwright의 Chromium을 사용합니다. 다른 브라우저를 사용하려면 `SC_CHANNEL`을 지정합니다
(예: Edge는 `SC_CHANNEL=msedge`).

실제 사용 경로의 시험 (아이콘을 누르는 동작부터 저장까지. Xvfb와 python-xlib가 필요합니다):

```bash
xvfb-run -a -s "-screen 0 1400x900x24" node tests/realflow.mjs
```
